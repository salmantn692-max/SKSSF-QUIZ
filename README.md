# 🏆 ക്വിസ് മാസ്റ്റർ - Malayalam Quiz Web & Android App

ഒരു സമ്പൂർണ്ണ മലയാളം ക്വിസ് മത്സര പ്ലാറ്റ്‌ഫോം. വിദ്യാർത്ഥികൾക്ക് ബ്രൗസറിലൂടെ നേരിട്ട് പരീക്ഷ എഴുതാനും, അഡ്മിന് തത്സമയം ചോദ്യങ്ങളും മാർക്കുകളും നിയന്ത്രിക്കാനും സാധിക്കുന്നു.

---

## 🌐 GitHub Pages വഴി 1 മിനിറ്റിൽ സൗജന്യമായി ലൈവാക്കാം:

നിങ്ങൾ പ്രോജക്റ്റ് GitHub-ലേക്ക് പുഷ് ചെയ്തുകഴിഞ്ഞാൽ, താഴെ പറയുന്ന ലളിതമായ 2 സ്റ്റെപ്പുകൾ വഴി ലൈവ് വെബ് ലിങ്ക് നിർമ്മിക്കാം:

1. നിങ്ങളുടെ **GitHub Repository** പേജ് തുറക്കുക.
2. മുകളിലുള്ള **Settings** ടാബിൽ ക്ലിക്ക് ചെയ്യുക.
3. ഇടത് മെനുവിൽ നിന്ന് **Pages** തിരഞ്ഞെടുക്കുക.
4. **Build and deployment** എന്നതിന് താഴെ:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (അല്ലെങ്കിൽ `master`), ഫോൾഡർ `/ (root)` സെലക്ട് ചെയ്ത് **Save** അമർത്തുക.
5. 1 മിനിറ്റിനുള്ളിൽ GitHub നിങ്ങൾക്ക് സൗജന്യമായ ഒരു ലൈവ് വെബ്സൈറ്റ് ലിങ്ക് നൽകും (ഉദാഹരണത്തിന്: `https://yourusername.github.io/your-quiz-repo/`).

## 🚀 പ്രധാന സവിശേഷതകൾ (Features)

### 👨‍🎓 വിദ്യാർത്ഥി പോർട്ടൽ (Student Portal):
- **രജിസ്റ്റർ നമ്പർ ലോഗിൻ**: കുട്ടികൾക്ക് അവരുടെ രജിസ്റ്റർ നമ്പർ നൽകി പരീക്ഷ തുടങ്ങാം.
- **തത്സമയ കൗണ്ട്ഡൗൺ ടൈമർ**: ഓരോ ചോദ്യത്തിനും നിശ്ചിത സമയം.
- **വിവിധ തരം റൗണ്ടുകൾ**:
  - സാധാരണ MCQ ചോദ്യങ്ങൾ
  - ഫോട്ടോ തിരിച്ചറിയൽ റൗണ്ട് (Image Identification with Fullscreen Zoom)
  - ഓഡിയോ ചോദ്യങ്ങൾ (Audio prompt rounds with Web Audio sound effects)
- **ഇൻസ്റ്റന്റ് സ്കോർ കാർഡ് & റിവ്യൂ**: പരീക്ഷ കഴിഞ്ഞയുടൻ മാർക്കും ശരിയുത്തരങ്ങളും വിവരണങ്ങളും കാണാം.

### 🔐 അഡ്മിൻ പാനൽ (Admin Portal):
- **പാസ്‌വേഡ് സംരക്ഷണം**: സ്ഥിരസ്ഥിതി PIN `1234` അല്ലെങ്കിൽ നിങ്ങൾ മാറ്റുന്ന പാസ്‌വേഡ്.
- **ചോദ്യ ശേഖരം (Question Bank)**: ചോദ്യങ്ങൾ ചേർക്കാനും എഡിറ്റ് ചെയ്യാനും ഡിലീറ്റ് ചെയ്യാനുമുള്ള സൗകര്യം.
- **വിദ്യാർത്ഥി മാനേജ്‌മെന്റ്**: വിദ്യാർത്ഥികളുടെ ലിസ്റ്റ്, റീ-ടെസ്റ്റ് സൗകര്യം.
- **തത്സമയ ലീഡർബോർഡ്**: 🥇 🥈 🥉 റാങ്ക് ലിസ്റ്റും മാർക്കുകളും ഒറ്റ ക്ലിക്കിൽ Excel/CSV ആയി ഡൗൺലോഡ് ചെയ്യാം.
- **ഇവന്റ് ബ്രാൻഡിംഗ് & PIN മാറ്റൽ**: ഇവന്റ് പേര്, സംഘാടകർ, അഡ്മിൻ പാസ്‌വേഡ് എന്നിവ ബ്രൗസറിൽ തത്സമയം മാറ്റാം.
